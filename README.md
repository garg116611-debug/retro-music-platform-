# 🎵 SwarSmriti - Retro Indian Music Platform

> *Echoes of Indian Music Legends*

A premium retro music platform celebrating legendary Indian artists and timeless melodies. Experience the golden era of Indian music through a modern, beautifully designed interface.

## ✨ Features

- **🏆 Legendary Artists** - Explore music from Jagjit Singh, Lata Mangeshkar, Kishore Kumar, A.R. Rahman, and more
- **🎭 Mood Explorer** - Filter songs by mood (Nostalgic, Romantic, Energetic, Devotional, etc.) with intensity control
- **▶️ YouTube Integration** - Legal music playback via embedded YouTube videos
- **❤️ Favorites** - Save your favorite songs locally
- **🔍 Smart Search** - Search for artists, songs, or albums
- **🎨 Premium UI** - Glassmorphism design with warm retro aesthetics

## 🎨 Design

The platform features a premium retro aesthetic with:
- **Deep Teal** backgrounds
- **Warm Amber Gold** accents
- **Burgundy** highlights
- **Glassmorphism** card effects
- **Smooth animations** and micro-interactions
- **Floating particles** background effect

- And more...

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/garg116611-debug/retro-music-platform-.git
   ```

2. Open `index.html` in your browser

3. Enjoy the music! 🎵
